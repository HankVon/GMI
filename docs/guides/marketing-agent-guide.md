# SSM 营销智能体 — 使用与接入指南

> 2026-08 交付。本文档说明如何在 SSM 平台上使用「营销智能体」三大模块：
> **GEO 监测 / 内容工厂 / 智能体总览**，以及如何接入真实 AI 引擎。

---

## 一、模块总览

```
┌────────────────────────────────────────────────────────────┐
│ 感知层  GEO 监测 (/workspace/geo)                          │
│   手动粘贴 / crawl4ai 抓取 / OpenAI 兼容 API 采集 AI 回答    │
│   → 解析引用来源、提及实体、品牌可见性                        │
├────────────────────────────────────────────────────────────┤
│ 决策层  智能体总览 (/workspace/marketing)                   │
│   商机评分(意向/招标/中标三源) + 内容选题推荐                │
├────────────────────────────────────────────────────────────┤
│ 执行层  内容工厂 (/workspace/content)                      │
│   行业报告 / FAQ / 公司档案 / 文章 自动生成                  │
│   → 草稿 → 审核 → 发布(人工闸门)                           │
├────────────────────────────────────────────────────────────┤
│ 反馈层  GEO 引用回流 → 选题迭代(闭环)                       │
└────────────────────────────────────────────────────────────┘
```

## 二、快速开始(3 步跑通闭环)

1. **配置品牌词**：进入「营销智能体 → GEO 监测」→ 右上角「品牌词/行业词」，填写
   **本公司全称与简称**(如 "XX地质勘查有限公司")。这是识别「AI 是否提及你」的依据。
2. **录入一条 AI 回答**：在豆包/DeepSeek/秘塔/百度AI搜索里搜行业问题
   (如 "生态修复工程 招标 公司 推荐")，把回答全文粘贴到「手动录入回答」→ 保存并解析。
   系统会抽取：引用来源、提及公司、你的品牌是否出现及排名。
3. **生成并发布内容**：进「内容工厂」→「智能生成内容」→ 选「行业数据报告」→ 生成草稿
   → 提交审核 → 发布。回到「智能体总览」查看闭环指标。

## 三、GEO 监测详解

### 3.1 三种采集适配器

| 适配器 | 说明 | 适用场景 |
|---|---|---|
| `manual` 手动粘贴 | 在 AI 引擎里搜完把回答粘回来 | 默认/兜底，最稳 |
| `crawl4ai` 网页抓取 | 用本地 crawl4ai 抓引擎网页(URL 支持 `{kw}` 占位) | 需 crawl4ai 服务运行 |
| `openai_api` 兼容API | 调 OpenAI 兼容 chat/completions(如 DeepSeek API) | 有 API Key 时最自动化 |

### 3.2 配置真实引擎(openai_api 示例)

以 DeepSeek 开放平台为例（"引擎配置 → 新增引擎"）：

- 名称: DeepSeek API
- 编码: `deepseek_api`
- 适配器: `openai_api`
- API 端点: `https://api.deepseek.com/chat/completions`
- API Key: 你的 `sk-...`
- 模型名: `deepseek-chat`

保存后，在「关键词任务」里把该引擎加入绑定，点「触发自动采集」即可无人值守采集。
定时任务每天 07:00 自动执行(GEO 监测)。

### 3.3 看板指标

- **AI 回答监测**: 近 30 天累计采集的回答条数
- **提及本公司 / 可见率**: 回答中出现品牌词的条数与占比(核心 KPI)
- **高频引用来源**: AI 回答引用的站点/来源 → 反向告诉你要在哪些平台补内容
- **被提及公司**: 同行/竞品在 AI 回答中的提及频次 → 竞争对标

## 四、内容工厂详解

| 内容类型 | 数据来源 | 产出形态 |
|---|---|---|
| 行业数据报告 | 中标/意向/招标 统计(区域/类型/金额) | Markdown 行业简报(带数据窗与统计) |
| 行业 FAQ | 行业关键词 + 平台数据 | 结构化问答(利于 FAQPage 标记) |
| 公司档案页 | 单位信息 + 平台业绩 | 企业画像内容(实体一致性) |
| 通用文章 | 主题 + 平台数据佐证 | 观点文章 |

> 生成默认走本地 Ollama(qwen-graphrag)；Ollama 不可用时自动降级为**确定性数据模板**，
> 保证链路永远可用。所有生成内容均为草稿，需人工审核后发布——这是内容合规闸门。

## 五、智能体总览(闭环看板)

四环指标一屏总览：

- **感知层**: GEO 监测回答数 / 品牌可见数
- **决策层**: 高价值商机数 / 内容选题数
- **执行层**: 内容资产总数 / 已发布数
- **反馈层**: 引用来源数 / 被提及公司数

下方「高价值商机」按 关键词命中+地域+时效+金额 评分排序；
「内容选题推荐」综合 **数据热点 / GEO 可见度缺口 / 引用源缺口** 三信号给出选题，
可一键「生成内容」直达内容工厂。

## 八、进阶能力（已交付）

### 8.1 JSON-LD 结构化标记生成器

内容工厂详情页 → 「生成 JSON-LD」：把内容转成 Schema.org 结构化标记，
一键复制 `<script type="application/ld+json">` 代码，粘贴到官网对应页面即可：

| 内容类型 | Schema.org 类型 | 说明 |
|---|---|---|
| 公司档案页 | `Organization` | 从平台 company 主数据取名称/地址/法人/信用代码/业绩，实体一致 |
| 行业 FAQ | `FAQPage` | 问答对结构化（AI 回答最常引用的格式） |
| 行业数据报告 | `Dataset` | 统计数字 → `variableMeasured`，可验证数据 |
| 通用文章 | `Article` | 标题/摘要/正文/作者 |

### 8.2 GEO 反馈回流（闭环反馈环）

发布的内容被 AI 引用后自动回链：

- 每次解析 AI 回答时，若其「引用来源」域名命中已发布内容的发布链接域名，
  自动写入该内容的 `geo_feedback`（引用次数 / 最近引用时间）。
- 内容工厂详情页显示「🎉 已被 AI 引用 N 次」；智能体总览反馈层显示「内容被AI引用」数。
- 手动全量回链：`POST /api/v1/content/feedback/relink`。

> 让闭环真实生效的关键：把内容工厂产出的 JSON-LD 挂到官网后，**把官网域名配进
> 发布渠道的 url_prefix**，此后 AI 引用官网即自动回流。

### 8.3 引擎连通性测试

引擎配置表每行新增「测试」按钮：openai_api 会实际发一条消息验证 Key 与端点；
crawl4ai 探测服务可达性；manual 直接提示无需测试。

## 九、演进建议(下一步)

1. **接真实 API 引擎**：配置 DeepSeek/豆包(火山方舟)等官方 API Key，采集全自动。
2. **官网 JSON-LD**：用内容工厂产出的公司档案/FAQ 生成 JSON-LD(Schema.org)，挂到官网，
   提升 AI 引擎对品牌实体的结构化认知。
3. **发布自动化**：对接公众号/知乎/百家号开放接口，把「审核通过」与「自动发布」打通。
4. **线索转化**：商机评分结果接入投标团队工作流(CRM/待办)，形成 商机→跟进→中标 闭环。
