## 一、背景

GMI 后端是一套**公共资源交易公告的爬虫聚合系统**，核心两张表：

- `web_source`：数据源（含 `url`、`scrape_mode`、`query_config`、`include_urls`、`max_pages`、`enabled`、`is_deleted`、`last_run_result` 等字段）
- `web_clue`：抓取后入库的公告线索

爬虫服务 `crawl4ai_server.py` 提供 `query`（SPA+JSON 接口）、`crawl`（HTML 列表页整站）、`scrape`（单页）三种模式。目标是把四川/新疆等地市州公共资源交易中心的「工程建设、政府采购、土地矿权、矿业权、中标公示」等公告抓成线索，供地质/矿业价值线索匹配使用。

## 三、涉及的功能模块

- **数据源管理**：`web_source`（启用/禁用、抓取配置、运行结果）
- **线索入库**：`web_clue`
- **爬虫服务**：`crawl4ai_server.py`（query / crawl / scrape 三种请求）+ 客户端 `app/services/crawl4ai_client.py`
- **抓取调度**：`app/api/v1/web_clues.py:_run_source_crawl(db, src, task_id)` 按 `scrape_mode` 分发
- **省级聚合源**：四川省（id57）、新疆省级源对市州的覆盖

## 四、技术实现方式

1. **域名与可达性核实**：`web_search` 找官方域名 → 在 docker 容器内用 python（`urllib` + 跳过证书校验）做 HTTP/浏览器级联通测试，区分「DNS 失败 / 连接拒绝 / 超时 / 反爬空页 / 被占跳转」。
2. **列表页定位**：对可达站点，爬首页提取导航与列表链接，定位真实 HTML 列表页 URL 与城市码。
3. **抓取配置**：`url` 指向列表页，`scrape_mode=crawl`，`config` 里配 `css_selector`（列表行）、`link_text_pattern`、`detail_page_wait`、`is_detail_json` 等。
4. **入库验证**：跑完各源后查 `web_clue` 计数，确认**真实出数**（而非假 200）。
5. **触发抓取**：
   ```bash
   docker exec ssm-backend python -c "
   from app.database import SessionLocal
   from app.models.web_source import WebSource
   from app.api.v1 import web_clues as wc
   db = SessionLocal()
   src = db.query(WebSource).get(<id>)
   print(wc._run_source_crawl(db, src, task_id='manual'))
   "
   ```
6. **数据库操作**：`docker exec -i ssm-mysql mysql -ussm_user -pssm_pass ssm < file.sql`。

## 五、关键认知

### 运行架构（很重要）
真正执行抓取的是 **Windows 主机上的 crawl4ai 服务（conda 环境 `GMI`）**，不是 docker 容器。错误栈可见路径 `E:\Software\miniconda3\envs\GMI\Lib\site-packages\crawl4ai\...`。docker 后端容器只是调度层，且容器自身有外网、但抓取不经过它。

因此：**宿主机的网络/代理状况直接决定抓取成败**。这也解释了为什么「docker 容器内 urllib 能拿到 200，但 crawl4ai 抓取却 ERR_CONNECTION_TIMED_OUT」——两者走的是不同的网络出口。

### query 模式对新点平台无效
`query` 模式的默认参数（`captcha_img_keyword=getVerify`、`api_url_keyword=selectInfoForIndex`、`result_rows_jsonpath=data.rows`、详情页 `/maincms-web/article`）是专为「四川政府采购网」SPA+JSON 接口调的，对 dedao 新点平台（HTML 列表页）完全不适用。正确做法是把 `url` 指向列表页并改用 `crawl` 模式。

## 九、附：各源接入要点速查

- **新点平台（dedao）**：`url` 指向 HTML 列表页（如 `…/pub/jyxx/list.html?menuCode=JYGCJS&areaCode=`），`scrape_mode=crawl`，`max_pages≈30`。切勿用 query 模式。
- **列表页 URL 须真实可达**：用浏览器/crawl4ai 验证能出正文，而非仅 HTTP 200（很多旧域名 200 是代理缓存或占位页）。
- **多模块扩展**：同一市州按 `menuCode`（工程建设 JYGCJS / 政府采购 JYZFCG / 土地矿权 JYTD 等）开多个子源。
- **特殊子系统**：攀枝花土地矿权在独立端口 `:8084`（`ggzy.panzhihua.gov.cn:8084/TD/WSJM/TDXXGKList.aspx?type=230`）。
