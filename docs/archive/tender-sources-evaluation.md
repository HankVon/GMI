## 逐源评估与接入建议

### 1. 全国投资项目在线审批监管平台 `new.tzxm.gov.cn` ⭐⭐⭐（意向优质源）
- **性质**：全国投资项目立项审批/备案公示，含项目名称/投资额/建设单位/建设地点/拟开工时间
- **获取**：SPA(JS渲染)，列表接口需真实浏览器 → **crawl4ai query 模式**（已有 playwright+OCR 能力）
- **更新**：实时（新审批即时上）
- **登录/验证码**：公开栏目免登录；查询表单可能带验证码(可OCR)
- **反爬**：低
- **接入**：作为**意向性项目**核心源。按关键词(地质/勘察/地灾/生态)检索立项公示 → 入库 intent_notice
- **价值**：立项阶段即获取 → 提前于招标 3-6 个月，完美契合「提前获取」

### 2. 中国政府采购网 `www.ccgp.gov.cn` ✅（已有，增强）
- **性质**：政府采购公告（招标/中标/更正/意向）
- **获取**：静态可抓，公开招标栏目已验证 200
- **登录/验证码**：无
- **接入**：**已接入**(来源 id=8 ccgp_list)。增强：补充「采购意向」栏目(cggg/yxgg)

### 3. 中小企业梯度培育平台 `zjtx.miit.gov.cn`
- **性质**：中小企业资质申报，**非招标源**
- **接入**：**不建议**用于招标信息。可作企业资质参考(可选)

### 4. 全国公共资源交易平台 `www.ggzy.gov.cn` ⭐⭐⭐（中标优质源）
- **性质**：全国公共资源交易(招投标/土地/矿产/产权)，公告分类全
- **获取**：SPA，列表 URL 已变(404) → 需 crawl4ai **query/真实浏览器**解析
- **登录/验证码**：查询带验证码(可OCR)
- **反爬**：中（有访问频率限制）
- **接入**：作为**中标公告**核心源之一，与已有 ccgp 中标互补。新增来源，query 模式按关键词检索
- **价值**：覆盖工程建设/土地矿业权等政府采购网不覆盖的领域

### 5. 国家标准全文公开系统 `openstd.samr.gov.cn`
- **性质**：国家标准全文，**非招标源**
- **接入**：**不建议**。可选作「技术标准」知识库（关联项目技术/资质）

### 6. 公路水运工程管理 `hwdms.mot.gov.cn` ⭐⭐（人脉补充源）
- **性质**：全国公路建设市场信用信息（企业资质/业绩/人员/中标记录）
- **获取**：静态可抓(200, 含链接)
- **登录/验证码**：公开查询免登录
- **接入**：**人脉库补充源**——按公司名查其公路业绩/中标记录，丰富公司经营画像
- **价值**：公路类项目人脉验证

### 7. 中国能建电商 `rcpu.cweun.org`（实为全国水利建设市场信用信息平台）
- **性质**：**水利建设市场信用信息**（企业信用/业绩），非电商招标
- **获取**：静态可抓
- **接入**：**人脉补充源**（可选），水利类企业业绩查询；或纠正为正确 URL

### 8. 全国企业采购交易寻源询价 `www.cneptp.com` ⭐⭐⭐（意向优质源）
- **性质**：企业采购寻源/询价系统（工程施工寻源/商品寻源），大型央企采购意向
- **获取**：可抓(200)；列表查询需实测接口
- **登录/验证码**：询价详情可能需要账号（部分功能）
- **接入**：**意向性项目**补充源——央企工程施工寻源 = 潜在工程机会

## 关键提醒
1. **SPA 源**(txzm/ggzy)：必须走 crawl4ai query 模式（playwright 渲染 + OCR 验证码），不能直接 requests
2. **更新频率**：招标/中标源建议 6 小时一次；意向源（立项/寻源）建议 24 小时一次
3. **反爬策略**：所有源统一走 crawl4ai 单实例串行，间隔 3-5s，避免被封
4. **数据时效**：中标人脉库只留近两年（方案已定）；意向信息保留 90 天滚动
